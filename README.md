# ksolabs.me (v2 Cinematic Flight)

The personal portfolio for Kushal S, AI engineer. Rebuilt as a fully cinematic 3D scroll-driven flight experience.

## Tech Stack
- Next.js 14
- Tailwind CSS
- React Three Fiber / Drei / Three.js
- React Three Postprocessing
- GSAP & ScrollTrigger
- Lenis
- Zustand
- Maath

## Local Development
```bash
pnpm install
pnpm dev
```
